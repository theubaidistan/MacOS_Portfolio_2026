## 🖥️ Overview

A fully interactive **macOS-inspired portfolio** built with React and powered by smooth GSAP animations. Experience a realistic desktop environment — complete with a Dock, draggable windows, and a dynamic menu bar — all showcasing my work as a developer.

🌐 **Live Demo:** [mac-os-portfolio-2026.vercel.app](https://mac-os-portfolio-2026.vercel.app/)

---

## ✨ Features

- 🪟 **Draggable & Resizable Windows** — open, minimize, and close apps just like a real Mac
- 🔵 **Animated Dock** — macOS-style magnification effect on hover
- 🎨 **GSAP Animations** — buttery-smooth transitions and micro-interactions
- 🗂️ **Zustand State Management** — lightweight, scalable global state
- ⚡ **Vite** — blazing fast dev server and build tool
- 🌗 **Dynamic Wallpapers** — beautiful desktop backgrounds
- 📱 **Responsive Design** — adapts gracefully across screen sizes

## 🚀 Getting Started

### Prerequisites

- Node.js `>= 18.x`
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/mac-os-portfolio-2026.git

# Navigate into the project
cd mac-os-portfolio-2026

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```
